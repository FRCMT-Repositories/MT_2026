<h2>`model.glb`</h2>
Este modelo é a estrutura base do robô, ou seja, o chassi do projeto e todos os mecanismos estruturais fixos, qualquer mecanismo que realize movimento/articulação deve ser gerado separadamente.

Primeiro ponto e crucial para facilitar a configuração e entendimento do arquivo `config.json` é restringir o robô após a montagem completa, ao centro dos eixos X, Y e Z do CAD.
